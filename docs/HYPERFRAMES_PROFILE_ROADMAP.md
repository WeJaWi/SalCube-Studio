## Product objective

Add a new SalCube Studio profile that produces complete videos with original
HTML, CSS, SVG, Canvas, and GSAP motion rendered through HyperFrames. It must
not request stock footage, stock photos, AI images, AI video, or an avatar.
Narration, captions, music, and sound effects remain separate audio concerns;
all visible content must be generated by the HyperFrames composition.

The target is not a slideshow of reusable cards. Each project should receive
custom scene layouts, custom animation parameters, custom choreography, and
timing aligned to the finished narration. The system must remain deterministic,
seekable, resumable, inspectable, and safe to render on local and fleet workers.

## Non-negotiable product rules

- [x] Call the initial profile `hyperframes` until a final user-facing name is approved.
- [x] Set the profile's visible-media mix to 100% HyperFrames.
- [x] Never call stock, AI-image, AI-video, or avatar providers from this profile.
- [x] Treat any accidental external visual-provider call as a test failure.
- [ ] Allow voiceover, captions, music, and optional sound effects as audio tracks.
- [x] Make HTML the source of truth for the visual video.
- [x] Require a visual identity before composition authoring begins.
- [x] Require an entrance animation for every meaningful scene element.
- [x] Require a real transition between every pair of scenes.
- [x] Let the transition remove the outgoing scene; do not pre-fade intermediate scenes.
- [x] Allow exit animation only in the final scene.
- [x] Make all timelines deterministic and synchronously constructed.
- [x] Never use infinite repeats, wall-clock time, or unseeded randomness.
- [x] Make every generated project reproducible from its saved inputs and seed.
- [x] Show the user a cost ceiling before submitting paid language-model requests.
- [x] Preserve the existing VidForge/Spotify-compatible final export contract.

## Milestone gates

### Milestone A — deterministic engine proof

- [ ] A hand-authored 30-second multi-scene composition compiles and renders.
- [ ] Lint, validate, inspect, and animation-map checks pass.
- [ ] Every scene has animated entrances and every boundary has a transition.
- [ ] Repeated renders of sampled frames are deterministic.
- [ ] Cancellation leaves no orphaned browser or encoder process.
- [ ] The final MP4 passes the existing export validator.

### Milestone B — AI-authored short proof

- [ ] A brief becomes a validated blueprint rather than unconstrained raw HTML.
- [ ] The compiler produces a 60–120 second composition.
- [ ] The result uses no stock or generated visual assets.
- [ ] Timings align with actual narration word timestamps.
- [ ] The repair loop fixes seeded layout and timing failures within its budget.
- [ ] Actual model credits and every request are recorded.

### Milestone C — eight-minute production candidate

- [ ] An eight-minute English video completes on the main Mac.
- [ ] An equivalent project completes on a Windows worker.
- [ ] No visual-provider call is made.
- [ ] No scene is missing an entrance or transition.
- [ ] No unapproved overflow, collision, contrast, flashing, or caption violation remains.
- [ ] Narration drift and final stream durations remain within the export tolerance.
- [ ] Stop/resume works without duplicate paid requests or lost progress.
- [ ] A scene-only revision preserves locked scenes and the previous final video.
- [ ] Actual authoring use stays within the configured 1,000-credit ceiling.

### Milestone D — production release

- [ ] The profile is documented, tested, observable, budgeted, and owner-approved.
- [ ] Fleet compatibility and rollback paths are proven.
- [ ] Preview approval and final delivery states are distinct and recoverable.
- [ ] Representative videos pass full manual creative review.
- [ ] Quality and credit metrics remain stable across the release evaluation set.

## Recommended implementation order

1. Freeze the product contract and zero-external-visual safety rule.
2. Add the engine interface, profile skeleton, workspace, and runtime doctor.
3. Define blueprint/timeline schemas and build a deterministic compiler.
4. Prove a hand-authored 30-second render with full validation.
5. Integrate narration timestamps and the semantic timing resolver.
6. Add structured AI planning and composition authoring with hard budgets.
7. Add automated QA and bounded scene-local repair.
8. Add preview approvals, locking, and selective regeneration.
9. Prove the two-minute and eight-minute acceptance fixtures.
10. Integrate fleet rendering, analytics, delivery, and controlled rollout.

## Definition of done for the profile

The feature is done only when a user can submit a brief, approve a visual
identity and storyboard, receive a fully custom eight-minute HyperFrames video,
revise one scene without disturbing the rest, and obtain a verified final MP4
without any stock/image/video provider call. The job must survive restart,
respect its model-credit ceiling, expose all validation findings, render
deterministically on a compatible worker, and preserve the last known-good
deliverable throughout revisions.
